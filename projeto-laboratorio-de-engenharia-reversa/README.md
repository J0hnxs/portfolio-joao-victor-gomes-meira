 ## 📝 Descrição do Projeto
O **Neumorphic Studio** é uma ferramenta de engenharia de interface voltada para a criação de designs baseados em **Neumorfismo** (Soft UI). O sistema permite a manipulação precisa de propriedades de luz e sombra em tempo real, gerando códigos CSS complexos que simulam superfícies táteis e extrudadas, integrando conceitos de skeuomorfismo moderno com minimalismo digital.
 
Desenvolvido para agilizar o workflow de designers e desenvolvedores front-end, o motor do projeto calcula dinamicamente a dispersão de sombras (dark e light shadows) com base na cor de fundo selecionada, garantindo que o contraste e a profundidade mantenham a fidelidade visual necessária para interfaces de alta qualidade.

 ## 🚀 Tecnologias Utilizadas
* **Core:** JavaScript (ES6+) para manipulação dinâmica de DOM.
* **Estilização:** CSS3 Avançado com foco em variáveis e algoritmos de `box-shadow`.
* **Frontend:** React (Arquitetura de componentes reutilizáveis).
* **Engine de Cores:** Algoritmos de manipulação hexadecimal para geração automática de tons claros e escuros.
* **Layout:** Flexbox & Grid para responsividade total da ferramenta.
 
 ## 📊 Resultados e Funcionalidades
O projeto oferece uma experiência de "What You See Is What You Get" (WYSIWYG) para design de componentes:
* **Motor de Sombras Dual:** Geração automática de sombras positivas e negativas para criar o efeito de extrusão realista.
* **Manipulação de Formas:** Suporte nativo para diferentes estados de superfície: *Flat*, *Concave*, *Convex* e *Pressed* (inset shadow).
* **Code Generator Instantâneo:** Exportação direta de código CSS otimizado para implementação imediata em qualquer projeto web.
* **Visualização Multi-Escalar:** Ajuste preciso de border-radius, distância de sombra, intensidade e blur via sliders interativos.

 ## 🔧 Como Executar
1. Clone o repositório para sua máquina local.
2. Abra o arquivo `index.html` diretamente no seu navegador ou:
3. Se estiver usando a versão React:
   * Instale as dependências: `npm install`.
   * Execute o servidor de desenvolvimento: `npm start` ou `npm run dev`.
